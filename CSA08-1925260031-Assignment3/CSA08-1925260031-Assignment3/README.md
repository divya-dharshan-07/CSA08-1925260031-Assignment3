## How to run

Open a terminal in this repository and run, for example:

```bash
python --version
python Task01/rainfall.py
python Task02/tuples_copying.py
python Task03/complaints.py
python Task04/electives.py
python Task05/sensor_readings.py
python Task06/railway.py
python Task07/contact_merge.py
```

Run each program separately. The experimental sections use `time.perf_counter()` and `sys.getsizeof()`. Actual timings and memory values depend on your computer, Python version, and current system load. **Do not copy sample timing values from another computer**: execute the programs and record your own results in the report.
